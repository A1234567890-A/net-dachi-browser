# ネット断ちブラウザ

パソコンに触れていた時間を、24時間の帯・アプリごとの内訳・1週間の推移・世界との比較で見て回る Windows アプリです。
画面を真っ暗にして触れずにいると、その時間が星になって夜空にたまっていきます。

## ダウンロード

[Releases](../../releases/latest) から `NetDachiBrowser-<版>.exe` を落としてダブルクリックしてください。

- Windows（64ビット）専用
- 管理者権限は不要（ユーザーごとにインストール）
- Java を同梱しているので、Java のインストールは不要
- 署名がないため、初回は「Windows によって PC が保護されました」と出ることがあります。「詳細情報」→「実行」で進めます。

## 記録について

記録は自分のパソコンの CSV ファイルにだけ残ります。外に送るのは、世界銀行の公開 API への「国別のネット利用率」の問い合わせだけです。
ウィンドウのタイトルや画面の内容は読み取りません。

## 出典

- 国別の1日のネット利用時間：We Are Social & Meltwater (2024), "Digital 2024 Global Overview Report"（元データ：GWI）, https://datareportal.com/reports/digital-2024-global-overview-report
- 国別のネット利用率：World Bank, "Individuals using the Internet (% of population)" (IT.NET.USER.ZS), https://data.worldbank.org/indicator/IT.NET.USER.ZS
